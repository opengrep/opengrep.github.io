the most advanced open source SAST engine

  • 30+ languages

    From C, Java and Python to Apex, Elixir and Visual Basic, plus generic matching for templates like Jinja and ERB.

  • superior performance

    Pure OCaml 5 with multicore parallelism for maximal performance. Shipped as self-contained binaries for Linux, macOS and Windows.

  • cross-function & cross-file analysis

    Taint tracking follows data through functions, methods and fields, including higher-order functions and calls into the language's standard library.

## install

# installs the latest release into ~/.opengrep
$ curl -fsSL https://raw.githubusercontent.com/opengrep/opengrep/main/install.sh | bash
# run in PowerShell
PS> irm https://raw.githubusercontent.com/opengrep/opengrep/main/install.ps1 | iex
# 1. grab the binary for your platform from the releases page
#    opengrep_osx_arm64, opengrep_manylinux_x86, opengrep_windows_x86.exe, …
# 2. make it executable and put it on your PATH
$ sudo install -m 755 opengrep_osx_arm64 /usr/local/bin/opengrep
$ opengrep --version

→ github.com/opengrep/opengrep/releases
Every binary ships with a Cosign .sig and .cert. On Windows, keep opengrep.exe and its DLLs together in the directory you install them to.
