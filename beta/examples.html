## semantic matching

A rule is a pattern that looks like the code it finds. Opengrep matches it against the syntax tree, not the text, so import aliases, line breaks, argument order and values held in variables don't get in the way.

shell-true.yaml
rules:  - id: subprocess-shell-true    languages: [python]    severity: ERROR    message: shell=True runs the command through a shell (command injection risk)    pattern: subprocess.$FUNC(..., shell=True, ...)
deploy.py
import subprocessfrom subprocess import run as shdef deploy(branch):    subprocess.call("git checkout " + branch, shell=True)    sh(f"make release BRANCH={branch}", shell=True)    use_shell = True    subprocess.Popen(        ["make", "clean"],        cwd="/srv/app",        shell=use_shell,    )    subprocess.run(["make", "test"], shell=False)
output

## cross-function taint analysis

A taint rule says where untrusted data comes from (sources), where it must never end up (sinks) and what makes it safe (sanitizers). With --taint-intrafile, Opengrep follows the data through function calls, return values, lambdas and higher-order functions.

command-injection.yaml
rules:  - id: command-injection    mode: taint    languages: [javascript]    severity: ERROR    message: User input reaches a shell command    pattern-sources:      - pattern: req.query      - pattern: req.body    pattern-sanitizers:      - pattern: shellescape(...)    pattern-sinks:      - pattern: exec(...)
server.js
const express = require("express");const { exec } = require("child_process");const shellescape = require("shell-escape");const app = express();function tarCommand(dir) {  return "tar czf /backups/latest.tgz " + dir;}function escape(dir) {  return shellescape([dir]);}app.get("/backup", (req, res) => {  exec(tarCommand(req.query.dir));});app.post("/backup-all", (req, res) => {  req.body.dirs.map(tarCommand).forEach((cmd) => exec(cmd));});app.get("/backup-safe", (req, res) => {  exec(tarCommand(escape(req.query.dir)));});
output
$ opengrep scan --taint-intrafile -f command-injection.yaml server.js

  • line 20each entry of req.body.dirs passes through map(tarCommand) and a lambda before reaching exec.
  • line 24no finding: the input goes through escape(), which calls the sanitizer.
